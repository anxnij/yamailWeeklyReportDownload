Desktop-приложение на Python для автоматического получения актуальной Excel-выгрузки из Яндекс.Почты. Реализовано подключение к почтовому ящику через IMAP SSL, поиск последнего письма от заданного отправителя или домена в нескольких папках, скачивание Excel-вложения либо файла по ссылке из письма, безопасная замена итогового файла через временный .tmp-файл, сохранение настроек в JSON, графический интерфейс на Tkinter, фоновая проверку по временному окну и ежедневный автозапуск через Windows Task Scheduler.
В работе выполнено:
Работа с email-почтой через IMAP и библиотеку imaplib.
Авторизация в почтовом ящике через IMAP SSL.
Поиск последнего письма от заданного отправителя или домена.
Проверка нескольких почтовых папок: INBOX, Рассылки, Spam, Спам.
Чтение и разбор email-сообщений через модуль email.
Декодирование MIME-заголовков и тем писем.
Обработка multipart-писем и извлечение текста из text/plain и text/html.
Поиск ссылок в тексте письма через регулярные выражения.
Фильтрация ссылок по заданному домену.
Скачивание Excel-вложений из писем.
Скачивание файла по ссылке из письма через requests.
Безопасная запись файла через временный .tmp-файл с последующей заменой итогового файла.
Автоматическое перезаписывание актуальной выгрузки в выбранной папке.
Сохранение пользовательских настроек в JSON-файл в AppData.
Вынесение технических параметров IMAP в отдельный config.json.
Валидация обязательных настроек: почта, пароль приложения, отправитель, папка сохранения и окно времени.
Реализация ручной проверки писем через интерфейс.
Запуск проверки в отдельном потоке, чтобы интерфейс не зависал.
Фоновый режим работы с периодической проверкой каждые 5 минут.
Настройка ежедневного окна автозапуска по времени.
Поддержка silent-режима через аргумент командной строки --silent.
Автоматическое завершение silent-режима после окончания временного окна.
Создание и удаление ежедневной задачи через Windows Task Scheduler.
Поддержка запуска как Python-скрипта и как собранного .exe.
Логирование действий программы в интерфейсе с датой и временем.
Обработка ошибок подключения к почте, отсутствия писем, вложений, ссылок и ошибок скачивания.
