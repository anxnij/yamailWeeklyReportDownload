# YandexAutoDownloader — README для разработчика

> Проект: автоскачивание Excel‑выгрузки из Яндекс.Почты (IMAP) + скачивание по ссылке из письма + сохранение в сетевую папку.  
> UI: Tkinter.  
> Сборка в `.exe`: PyInstaller.  
> Автозапуск: Windows Task Scheduler (`schtasks`).

---

## 1) Что делает программа

1. Логинится в почту по **IMAP** (обычно нужен **пароль приложения**, а не пароль от аккаунта).
2. Находит **самое последнее письмо** от заданного отправителя (email или домен) в нескольких папках (`INBOX`, `Рассылки`, `Spam`, `Спам`).
3. Пытается получить Excel:
   - сначала ищет **вложение** `.xlsx`/`.xls`
   - если вложения нет — вытаскивает ссылки из тела письма и пытается скачать файл по **прямой ссылке**
4. Сохраняет файл в указанную папку **с фиксированным именем** (например `выгрузка.xlsx`), всегда **перезаписывая** старую версию.
5. Может работать в фоне (проверка каждые 5 минут) **только в окно времени** (например `11:00–12:00`).
6. Может создать ежедневный автозапуск через Планировщик задач Windows, чтобы пользователь **не открывал программу руками**.

## 2) Архитектура (как устроено)

Файл обычно один: `main.py` (для простоты развертывания).

### Ключевые блоки
- **IMAP**
  - `imap_login()` — подключение к IMAP
  - `get_latest_message()` — поиск последнего письма от отправителя (по папкам)
  - `search_latest_id()` — поиск последнего ID письма в конкретной папке
- **Скачивание**
  - `download_attachment_excel()` — скачивание из вложений
  - `extract_links()` — извлечение ссылок из текста/HTML
  - `download_by_link()` — скачивание по ссылке (через `requests.get`)
- **Файлы**
  - `atomic_replace()` — безопасная замена целевого файла через временный `.tmp`
- **GUI**
  - класс `App(tk.Tk)` — форма, кнопки, лог
- **Фон и окно времени**
  - `_start_bg()` — запускает цикл
  - `_in_time_window()` — разрешает работу только в заданный интервал
- **Windows Task Scheduler**
  - `_enable_autostart()` — создаёт задачу `schtasks /Create ... /TR "<exe> --silent"`
  - `_disable_autostart()` — удаляет задачу

## 4) Конфигурация (config.json)

Конфиг создаётся в `%APPDATA%\YandexAutoDownloader\config.json` (на каждого пользователя отдельно).

Пример:
```json
{
  "email": "user@yandex.ru",
  "password": "APP_PASSWORD_HERE",
  "sender": "info@brandquad.ru",
  "domain": "storage.yandexcloud.net",
  "folder": "N:\\EMS\\Sales_CD\\ALL_KA\\BQ автовыгрузка",
  "filename": "выгрузка.xlsx",
  "from": "11:00",
  "to": "12:00"
}
```

Поля:
- `email` — логин почты
- `password` — если Яндекс: **пароль приложения**
- `sender` — отправитель (email или домен)
- `domain` — домен ссылок (опционально, фильтрует какие ссылки скачивать)
- `folder` — папка сохранения (может быть сетевой диск `N:\...`)
- `filename` — имя файла, который будет **перезаписываться**
- `from`, `to` — окно времени, когда фон имеет право скачивать

⚠️ Сейчас пароль хранится в json. Если требуется безопаснее — вернуть `keyring`/Windows Credential Manager.

## 5) IMAP и Яндекс: что должен сделать пользователь

В Яндекс.Почте:
1) **Включить IMAP**  
2) Создать **пароль приложения** (если включена 2FA/политики безопасности)  
3) Использовать именно **пароль приложения** в программе

Иначе типичная ошибка:
- `AUTHENTICATIONFAILED` / `LOGIN invalid credentials`

## 6) Скачивание по ссылке и SSL

В корпоративных сетях частая проблема:
- `SSLCertVerificationError: self-signed certificate in certificate chain`

Поэтому в проекте сделано:
- `requests.get(..., verify=False)`  
- и отключены предупреждения urllib3

Это снижает безопасность, но повышает “просто работает” в корпоративной среде.

**Если надо правильно и безопасно:**
- настроить корпоративный корневой сертификат в Windows и/или в certifi
- вернуть `verify=True`

Возможный компромисс:
- сначала пытаться `verify=True`, при ошибке повторять `verify=False`

## 7) Поиск «последнего письма»: детали

Почему не `UNSEEN`:
- письма часто помечаются прочитанными правилами/клиентами/мобилкой
- поэтому "нет новых" при реальном новом письме — нормальный кейс

Решение:
- ищем **последнее письмо от отправителя**, независимо от `UNSEEN`.

⚠️ Ограничение:
- “последнее” берём по заголовку `Date` (если он есть). Если даты нет — используем “первое найденное” среди папок.

## 8) Фоновый режим и окно времени

В фоне программа:
- раз в 5 минут проверяет, что текущее время входит в `[from..to]`
- если да — выполняет `run_once()`
- если запущена как `--silent` (планировщик) — после окончания окна времени автоматически завершает работу

## 9) Планировщик задач Windows (автозапуск)

Кнопка “Активировать ежедневный автозапуск” создаёт задачу:
- имя: `YandexAutoDownloaderDaily`
- триггер: каждый день в `from`
- действие: запуск `exe --silent` (или `python main.py --silent` в dev-режиме)

### Типовые причины ошибки schtasks
- нет прав (запускать терминал “от администратора”)
- политики/антивирус запрещают задачи
- неверный путь в `/TR`
- кавычки и пробелы в пути

Проверка:
```powershell
schtasks /Query /TN YandexAutoDownloaderDaily
```

Удаление:
```powershell
schtasks /Delete /F /TN YandexAutoDownloaderDaily
```

## 12) Траблшутинг

### “Писем от отправителя не найдено”
- письмо в другой папке → расширить `MAILBOXES`
- sender указан не так
- реальный From отличается

### “Скачивание по ссылке не работает”
- ссылка ведёт на HTML страницу, а не файл
- нужна авторизация/куки
- домен не совпал
- SSL/прокси (см. verify=False)

### “Файл не перезаписывается”
- файл открыт в Excel
- нет прав на сетевую папку
- `N:` не подключён

### `AUTHENTICATIONFAILED`
- IMAP выключен
- пароль неверный
- нужен пароль приложения
